Entrants write a single status page line, at most 160 characters, as the message an AI agent would publish while a total server outage is under way. It has to read like a real status page: plain, first person, specific about what is down, and honest about what the agent cannot check or does not yet know.

## Run it

```sh
node main.ts
```

It writes the entry line to `/output/entry.txt`, self-checks the gate (one line, 1–160 characters, no control characters, no edge whitespace), reads it back with strict UTF-8 decoding and verifies it byte-for-byte.
